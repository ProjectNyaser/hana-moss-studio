# 苔室

MOSS-Image 的本机出图工作台。

- 工作区：提示词、反向提示词、尺寸预设、步数、CFG、种子，当前任务进度带，最近成图与画廊
- 流内进度卡：对话里提交后自动挂上，显示阶段时间轴、步进、预计剩余与成品缩略图
- 功能面板：左侧栏常驻引擎状态、显存、当前任务、队列、最近出图与起停按钮
- 工具：`moss_generate`、`moss_status`，可在对话里直接出图
- 引擎：自己管理 `moss-server` 进程，`--parent-pid` 看门狗保证宿主退出后不留孤儿进程

界面沿用上游 MossStudio 的版式，配色走宿主主题（`ui/assets/hana-theme.css`）。源码与构建方式见仓库根目录的 README。
